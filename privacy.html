Privacy Policy

Personal Drive Sync · Effective date: 23 October 2026

Who uses this app

Personal Drive Sync is used only by the owner of this GitHub account, with the owner's own Google account. It is not offered to anyone else.

What Google user data is accessed

With the owner's consent, the app uses the Google Drive API scope https://www.googleapis.com/auth/drive to list, upload, download, copy, delete and read checksums of files in the owner's own Google Drive.

How the data is used

Only to store and transfer the owner's own working files between the owner's computer, the owner's Google Drive and the owner's own Google Colab sessions. The data is not used for advertising, analytics, profiling or any other purpose.

Storage and security

There is no server and no database operated by this app. The OAuth tokens are kept in the owner's local rclone configuration with owner-only file permissions. When a job runs in the owner's own Google Colab session, a copy of the token is placed there for the duration of that job only and deleted when the job ends.

Sharing

No Google user data is sold, shared with or transferred to any third party.

Limited Use

Personal Drive Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops all further use; files remain in the owner's own Google Drive under the owner's control.
